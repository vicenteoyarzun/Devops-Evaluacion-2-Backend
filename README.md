DevOps - Evaluación Parcial N°2 (Innovatech Chile)Este proyecto consiste en la contenedorización y despliegue automatizado del backend para la empresa Innovatech Chile.  🐳 ContenedorizaciónEl proyecto utiliza Docker para asegurar que la aplicación funcione en cualquier entorno:  Dockerfile: Configurado con multi-stage build para ser más eficiente y seguro.  Usuario No-Root: La aplicación se ejecuta con privilegios limitados por seguridad.  Docker Compose: Permite levantar el backend y la base de datos con un solo comando.  💾 Persistencia de DatosPara evitar la pérdida de información crítica, se utilizan volúmenes de Docker:  Se emplean Named Volumes para asegurar que los datos de la base de datos persistan incluso si los contenedores se reinician o eliminan.  🚀 Despliegue Automatizado (CI/CD)Se implementó un pipeline en GitHub Actions que se activa al hacer push a la rama deploy:  Build & Push: Crea la imagen de Docker y la sube al registro (Docker Hub/ECR).  Deploy: Actualiza automáticamente el servicio en la instancia AWS EC2.  Seguridad: Todas las credenciales de AWS y tokens se manejan de forma segura mediante GitHub Secrets.
